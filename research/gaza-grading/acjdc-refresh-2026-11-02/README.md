### Narrative organization-matching bug

Two independent substring mistakes were repaired with regression coverage:

- The input builder matched **ICAN inside American**, assigning unrelated labor
  and civic endorsers to its Israel-aligned list. Boundary-aware matching replaces
  that behavior while retaining real ICAN, JStreetPAC, Americans4Hindus and
  TrackAIPAC aliases.
- The output validator matched **OC Action inside AROC Action**, rejecting a
  legitimate AROC reference. Multiword name checks now respect boundaries.
  Rejected drafts and recovery receipts remain exact. Retry errors now tell the
  writer which references to omit.
